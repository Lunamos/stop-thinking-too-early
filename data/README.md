# Data

The programs, fact chains and toy tasks are generated by the experiment scripts, so nothing needs downloading for them.

MuSiQue (CC BY 4.0), SQuAD, HotpotQA, 2WikiMultihopQA and WikiText-103 are loaded from the Hugging Face hub. The fixed
selections used in the paper, including the 900 MuSiQue development questions, are exported to this folder with

    cd ../scripts && python export_qa_data.py
